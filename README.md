# Multitrack Inventory

Aplicación Android para la gestión y control de inventario, desarrollada en Kotlin con Android Studio.

## 📋 Descripción

**Multitrack Inventory** es una aplicación móvil que permite registrar, controlar y hacer seguimiento de inventarios. Incluye autenticación de usuarios y una interfaz intuitiva para la gestión de productos.

## ✨ Características

- 🔐 Inicio de sesión de usuarios
- 📦 Registro y control de inventario
- 🎨 Interfaz adaptable a diferentes tamaños de pantalla
- 🌐 Recursos centralizados (colores, strings, drawables)

## 🛠️ Tecnologías

- **Kotlin** — Lenguaje principal
- **Android Studio** — IDE
- **Gradle** — Sistema de construcción
- **XML** — Diseño de interfaces
